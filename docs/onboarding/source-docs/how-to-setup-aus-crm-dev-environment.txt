
Once you installed required software and setup system path, follow below procedure:
Checkout following projects: dataimport, datascraper, MyobService, NotificationService, pbxapp, waterfind.com.au, waterfindServiceModel . Please note to checkout only branch called “Iteration45”.
Once you checkout all the above projects, Take a copy of local-server-dev.properties.sample file and make it as local-server-dev.properties file. This is the main properties file for dev environment which need to be updated according to the location of your database and other files. Do this for the below listed projects.
dataimport, MyobService, Pbxapp, waterfind.com.au.

Eclipse Preferences for this project:
Go to Window-> preferences -> Java->Installed JREs , and select your java 1.7 home path. And compiler 1.7


Go to Window-> preferences -> Ant->Runtime, make sure your runtime is pointing to your ant-home directory.


Go to Window-> preferences -> Server->Runtime Environment, and add Resin 4.0

IMP Note: Don’t forget to restart the eclipse after changing the java version.
Project Buildpath settings:
Open properties for waterfind.com.au project->Java Build path and add JRE system library as follows:
Execution environment to point to JavaSE-1.6(jdk 1.7.9_80) 
And Java Compiler to point to 1.6 (See below)
Make sure to do this for the below mentioned projects
Waterfind.com.au, NotificationService, datascraper and dataimport. 
Other project has default jdk 1.7 in their build path



Change local-server-dev.properties file of waterfind.com.au project:
Uncomment resin.path property variable and update path to point to your resin home directory.
Change jdbc-waterfind.proxool.driver-url  variable to point to your local database
Change below file paths to point to your local workspace
file.docs.path= C:/Kris/Workspaces/WFAUSTrunk/waterfind.com.au/build-dev/waterfind/WEB-INF

To run the project in redundancy mode set the below property to true, we do this to avoid sending emails/SMS on certain operations. If the CRM is in redundant mode, it wont send emails out.

Running the build:
There are some build scripts for running different kinds of builds. 
Open Ant window: Click window->Show view->Ant-> Ant
Open build.xml files for all the projects here.



When you are first running run build-webapp under waterfind.com.au project which builds all the projects. This will take around 20mins to build entire project. 
After the build successfully completed, go to your resin home directory and open resin.conf file.
Add your directory path in the resin.conf file under host tag like below:
  <host id="*">
        <web-app id="/">
			 <document-directory>C:/Workspaces/ WFAUSDotsquares45/waterfind.com.au/build-dev/waterfind/</document-directory>
        </web-app>
    </host>

Now start Resin web server by running resin.exe which is located under following path:
C:\Programs\resin-3.1.10\win32
Open the project in your local IP at port 81:
http://192.168.5.13:81/index.html
