Three ways to drop the Adviser into the existing portal

Rebuilt in the live client portal's own skin — Poppins, brand blue #2b6da5 + the signature orange #f6891f right-border accent, the 64px icon rail, navy market title bar, and the same panels, tables and Buy/Sell buttons. Same visual language as today's market screen, so there's no jarring transition. These show three integration patterns, not three aesthetics.

One panel among many

What changed from the first pass. The initial three wireframes committed to bold, distinct aesthetics (editorial / dark terminal / mobile). They read well in isolation but — as you flagged — would clash with the current portal and make the transition jarring. These replacements adopt the portal's exact design tokens, so the adviser looks like a feature of the app it lives in. The open question is now placement, not styling.
